# Experience memory

If `status` lists `memory/`, read `memory/INDEX.md` and `memory/TIPS.md`; evidence
paths in them no longer exist. Use only the learned skills under `memory/skills/` and
tips whose observable preconditions match the current scene.

- Prefer a learned skill's pose recipe over its recorded coordinates: replay relative
  recipes from the current measured state, and reacquire any point the recipe anchors
  to.
- A tip describes a visible local effect under stated conditions. If this scene
  differs, verify the precondition first.
